## 0. ゴール（一言）

## 2. 要件（v1で確定済み・叩き台）
- md読み込み（ファイル選択/ドラッグ/貼り付け）→ `問N`/選択肢/`正解`/`解説`を自動解析
- 選択肢タップで解答 → **最後に一括採点**
- 結果画面：正答数・正答率・**各問の○×／自分の解答／正解／解説**、**間違いだけ絞り込み**
- **複数回の履歴を保存**（localStorage）→ **苦手ランキング**（間違い率順）＋**章別正答率**
- モード：全問／シャッフル／出題数指定／**間違いだけ復習**／**苦手だけ演習**
- 記録のJSONエクスポート・インポート・消去
- 端末内保存のみ（外部送信なし）、レスポンシブ、ライト/ダーク対応

**追加候補（未確定・要判断）**：通読専用ビュー（全問の問題＋正解＋解説一覧）、解答タイマー、分野タグ、間隔反復（苦手を一定間隔で再出題）。

## 4. mdのフォーマット（パーサ実装の要）
Coworkに以下の形で出力させてある。Codexのパーサはこれに合わせる：

```
## 第1章 人工知能とは
### 問1
（問題文）

- ア. 選択肢1
- イ. 選択肢2
- ウ. 選択肢3
- エ. 選択肢4

**正解：イ**
**解説：** （解説文）
```

**許容すべき揺れ**：全角/半角コロン（：/:）、`ア.`/`ア、`/`(ア)`/`①`、`正解`/`解答`/`正答`、複数正解（`正解：ア・ウ`）、章見出しは `##`・問見出しは `###`。
読めない問題は**除外＋一覧報告**する方針（採点を壊さない）。

## 5. Codex実行方法（このMacで確認済み）
```
codex exec -C ~/gken_app --sandbox workspace-write - < prompt.md
```
- `--sandbox` は `read-only | workspace-write | danger-full-access`。長文プロンプトはファイルにして `stdin(-)` で渡す。
- **モデル注意**：ChatGPTアカウント認証だと `gpt-5-codex` は不可。**`--model` を付けず既定（gpt-5.6-sol）で実行**。
- 動作確認：`codex --version` / `codex exec --sandbox read-only "1+1は?"`

## 6. 運用ループ

2. `codex exec` で構築

## 7. Claudeレビュー観点（チェックリスト）
- パーサが**実mdの全問を拾えるか**（「認識数」＝期待問数か。読めない問題の一覧）
- 単一/**複数選択**の正解判定が正しいか
- 採点・○×・解説表示・「間違いだけ」絞り込みの正確さ
- localStorage永続化、苦手ランキング（2回以上×間違い率）、章別集計の妥当性
- モバイル操作性、ダークモード、キーボード/フォーカス、アクセシビリティ

## 10. v1の設計メモ（Codexが踏襲/改良する際の参考）
- 単一HTMLファイル。外部依存なし（フォントはHiragino等のシステムスタック、CDN不使用）。
- 画面：ホーム（読み込み＋モード選択）／演習（1問ずつ）／結果（採点＋レビュー）／統計（苦手・章別・保存）。
- 保存キー：`localStorage['gken_quiz_stats_v2']`＝`{version, perQ:{[qid]:{seen,wrong,chapter,num,preview,hist[]}}, sessions:[]}`。
- 問題ID（`qid`）は `章|問番号|本文先頭60字` のハッシュで、md再読込でも安定。
- 複数正解は選択集合の完全一致で採点。未回答は不正解扱い。
- 既知の弱点：OCR揺れが大きいmdだとパース漏れが出る可能性 → §4の許容範囲を広げる余地あり。実mdでの「認識数」を必ず検証すること。
